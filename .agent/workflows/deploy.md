description: How to deploy the Diabetes Prediction Dashboard to Streamlit Community Cloud
---
Follow these step-by-step instructions to deploy your application:

1. **Host on GitHub**: Make sure the repository is fully committed and pushed to your GitHub at `https://github.com/Priyam2773/Diabetes-Prediction-System-`.
2. **Access Streamlit Community Cloud**: Go to [Streamlit Share](https://share.streamlit.io/).
3. **Log In**: Click "Connect with GitHub" or sign in with your GitHub account.
4. **Initiate App Deployment**: Click on the green "New app" button in the upper right.
5. **Configure Details**:
   - **Repository**: Select or type `Priyam2773/Diabetes-Prediction-System-`.
   - **Branch**: Specify `main`.
   - **Main file path**: Type `app.py`.
6. **Trigger Deployment**: Click "Deploy!".
7. **Monitor Progress**: Streamlit will bake your app, read `requirements.txt`, install dependency libraries, and run the app. It will make your app live on a custom sub-domain URL!
